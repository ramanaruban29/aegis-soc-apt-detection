# 08_ladder_v4: leakage-ladder experiments

Scripts, per-run results, figures and the summary workbook for "What a Single Run Hides:
A Leakage-Ladder Protocol for Repeated-Run Evaluation of Flow-Based APT Detectors"
(Rangan and Mascrenghe).

The datasets and dataset-derived arrays (.npy, .csv) are not included. See Data.

## Contents

| Path | Contents |
|---|---|
| scripts/ | Runners, patch script, data preparation and table helpers |
| results/ | One JSON file per run (one seed per file) |
| results/dapt/ | DAPT2020 result folders |
| results/cross_noae.log | DAPT2020 to CICAPT-IIoT transfer log |
| figs/ | Figures 1 to 3 (PDF, PNG, EPS) |
| results_workbook.xlsx | Summary sheets; values are medians over runs |

## Scripts

| Script | Purpose | Invocation |
|---|---|---|
| dapt_experiment.py | Original DAPT2020 runner (before v4). Input to the patch script. | Not used directly for the reported results |
| make_dapt_v4.py | Reads dapt_experiment.py, applies exact-match substitutions, writes dapt_experiment_v4.py | `python make_dapt_v4.py` (no arguments; paths set in file) |
| dapt_experiment_v4.py | DAPT2020, random benign. Generated by make_dapt_v4.py | `python dapt_experiment_v4.py N_SEEDS GAP {random,chrono}` |
| dapt_experiment_v4x.py | DAPT2020 with block benign, row mode, port shuffle | `python dapt_experiment_v4x.py N_SEEDS GAP {random,chrono,row} {random,block}` |
| cicapt_runner_v4.py | CICAPT-IIoT base variants | `python cicapt_runner_v4.py --mode {row,random5,random120,chrono,loso} --benign {random,block} --seeds N --feature-names PATH --out DIR` |
| cicapt_runner_v4x.py | CICAPT-IIoT with gated and port-shuffle variants; produced the `*_extra` folders | Same flags as v4, plus `--only-extra` |
| dapt_loao.py | DAPT2020 leave-one-activity-out; reads dapt_experiment_v4.py and writes to results_v4_loao_gap120 | `python dapt_loao.py [NS]` (default 5) |
| cross_dataset.py | DAPT2020 to CICAPT-IIoT transfer | `python cross_dataset.py [--seeds N] [--noae] [--check] [--summarize] [--map FILE]`; needs ts_full.npy, not included |
| make_figs.py | Figures 1 to 3 | `python make_figs.py --roots DIR [DIR ...] [--out figs]` |
| build_workbook.py | Builds results_workbook.xlsx | No arguments; paths set in file |
| extract_ts.py, dapt_prep.py | Data preparation | No arguments; paths set in file |

Both DAPT runners write to `/mnt/d/dapt_work/results_v4_{MODE}_gap{GAP}[_block]`.
Copy the output into `results/dapt/`. The LOAO script writes to `results_v4_loao_gap120`,
so back that folder up before rerunning it.

Dataset paths in every script are set for the authors' machine and must be edited before reuse.

## Model keys

| Key | Meaning |
|---|---|
| lgbm_full | Deployed model: AE score plus LightGBM on raw features |
| lgbm_noscore | Raw features only |
| lgbm_noports | Source and destination port columns removed |
| lgbm_full_clip | Deployed model, clipped score (CICAPT-IIoT check) |
| lgbm_full_unclip | Deployed model, unclipped score (DAPT2020 check) |
| *_portshuf | Same model with the two port columns permuted across all test flows |
| ae_only | Autoencoder reconstruction error alone |
| gated_ae_lgbm | Sequential gate then LightGBM (v4x only) |
| ada, et, gb, lgbm_tuned, rf | AdaBoost, Extra Trees, Gradient Boosting, tuned LightGBM, Random Forest |
| mlp | Multilayer perceptron |
| iforest, ocsvm | Isolation Forest, One-Class SVM (benign-only detectors) |

Threshold keys:
- CICAPT-IIoT: `fpr2e-05`, `fpr4e-05`, `fpr8e-05` = FPR targets 0.002%, 0.004%, 0.008%
- DAPT2020: `fpr0.002`, `fpr0.005`, `fpr0.01` = FPR targets 0.2%, 0.5%, 1%
- `mccrule` = threshold with the highest validation MCC

## Feature columns and port variants

`feature_names.json` lists `anomaly_score` first, then 63 raw features. The array stores the
raw features in columns 0 to 62 and the anomaly score in column 63, so array column c
corresponds to `names[c+1]`. This alignment was checked against the data: within each
Protocol_Type value, TCP and UDP flags are constant only under it.

- Source Port is array column 2, Destination Port is array column 3, Protocol Type is array column 4.
- `lgbm_noports` removes columns 2 and 3 (`keep_raw` in both CICAPT runners).
- `*_portshuf` permutes columns 2 and 3 (`allR[:, pc - 1]` for pc in 3, 4).
- Protocol Type is kept in every variant, so the port-shuffle results measure reliance on the two port columns only.

The JSON `ports` field lists `feat_Source_Port` and `feat_Destination_Port`, the names of those two columns.

## Checked reproductions

- Table 9 from saved JSON: lgbm_full 0.63 to 0.25 (CICAPT-IIoT, 5 s blocked), 0.86 to 0.29 (DAPT2020 row), 0.69 to 0.29 (DAPT2020 5 s blocked). lgbm_noscore and mlp also match.
- CICAPT-IIoT chronological, 10 runs: lgbm_full median MCC 0.0568, median FP 144.5 (Table 4: 0.057, 144).
- CICAPT-IIoT chronological, first 3 seeds: FP 46, 171, 53 (Section 7.7).
- DAPT2020 chronological, 20 runs (results_v4_chrono_gap5): lgbm_full median MCC 0.0077 (Table 4: 0.008).
- DAPT2020 chronological, 5 runs (results_v4_chrono_gap120): median MCC 0.0049 (workbook row "DAPT chronological, 120 s").

## Differences between the workbook and the paper

- The CICAPT_ladder chronological row uses the 3 base seeds (median MCC 0.0886, FP 53). Table 4 uses all 10 seeds (0.057, FP 144). Section 7.7 reports the 3-run set separately.
- Table 9 is computed from the JSON, not read from a workbook sheet.

## Notes

- Workbook values are medians over runs. Per-run values are in the JSON files.
- Chronological and leave-one-stage-out partitions are fixed, so their intervals and p values describe training randomness only.
- Gradient Boosting probabilities saturate near 1.0 under undersampling, so its low scores reflect the scoring, not model failure.
- DAPT2020 to CICAPT-IIoT transfer has near-zero MCC (`cross_noae.log`). The two datasets use different feature extractors, so this is not a valid test of generalisation.
